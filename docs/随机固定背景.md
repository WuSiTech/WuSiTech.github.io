# 随机固定背景（全站）

> 验收状态：已完成并在真实浏览器（无头 Edge + CDP）里逐页截图验证，见文末「验证记录」。

## 目标

1. 页面背景是一张**不随页面滚动**的大图（`position: fixed`）；
2. 非文章页（首页 / 关于 / 友链 / 下载 / 分类 / 标签…）从
   `data/remote_backgrounds.yml` 的远端图源里**随机**取一张；
3. 文章页：**只有 front matter 里显式写了 `banner`** 才用它当整屏背景；
   没写 banner 的文章（不管有没有 `cover`）和普通页面一样走随机图源。
   `cover` 只是首页卡片的缩略图，**不参与**背景；
4. 远端加载失败 / 超时就**自动回落到** `static/images/pool/bg/` 的本地图池（随机）；
5. 背景不拖慢首屏、不产生横向滚动条、不遮挡内容。

## 文件

| 文件 | 作用 |
| ---- | ---- |
| `layouts/partials/head/init.html` | **站点级覆盖**主题同名 partial（不改 `themes/`）：构建时把图源清单和当前页 banner 注入成 `window.__WUSI_BG__` |
| `static/css/wusi-bg.css` | 背景层样式 + 把主题的 `html/body/#wrap` 不透明底色放开 + 有 banner 的页面把 `#header` 那张图改成整屏固定背景 |
| `static/js/wusi-bg.js` | 选图、异步探测、淡入、失败回落、状态上报（`window.__wusiBg`）；页脚固定栏尺寸同步、悬停淡出、头部文字颜色采样也在这个文件 |
| `config/_default/hugo.yml` | `cascade: params.banner: false`：关掉「没有自定义 banner 就渲染站点默认 banner.webp」的老行为，省掉一次 155KB 的无用图片请求 |
| `config/_default/params.yml` | `injector.head_end` 引 CSS、`injector.body_end` 引 JS；头部去框/自适应颜色、页脚固定底栏的样式；副标题打字开关（`subtitle.typing`） |
| `layouts/partials/footer.html` | 站点级覆盖主题页脚：把 `#footer`、域名提示、BLOG 状态徽章一起包进页面最底部的整条通栏 `#wusi-footer-bar` |

数据来源（都不用手改代码）：

- 远端图源：`data/remote_backgrounds.yml` 的 `remote_backgrounds` 列表；
- 本地兜底：构建时用 `os.ReadDir "static/images/pool/bg"` 直接列目录，
  往这个目录里加 webp 就会自动进兜底池（不用改配置）。
  ⚠️ 图片本体在 `media` 孤分支，构建时由工作流拉到该目录（本地构建前先跑
  `python tools/fetch_media_pool.py`），详见 [图片池（media 分支）.md](图片池（media%20分支）.md)。

## 工作流程

```
页面加载
  └─ <head> 注入 window.__WUSI_BG__ = {banner, remote[...], local[...]}   （约 10KB，gzip ~3KB，不发请求）
  └─ /js/wusi-bg.js（defer）
       ├─ 本页有 banner → 样式表已经把 #header 里的 banner <img> 变成整屏固定背景，
       │                   JS 只等它加载完（失败则撤掉类名、藏掉坏图 → 走随机）
       │                   —— 一图两用，不会重复下载
       └─ 本页没有 banner → 从 remote 里随机抽一张（尽量不与上一次重复）
            ├─ 300ms 内远端还没好 → 先铺一张本地兜底图（100KB 级，快）
            ├─ 远端 onload → 远端图淡入覆盖（远端图 0.7~1MB，非阻塞）
            └─ 远端 onerror / 4s 超时 → 保留本地兜底图；本地图也坏就换一张
```

时间参数在 `static/js/wusi-bg.js` 顶部：`REMOTE_TIMEOUT = 4000`、`LOCAL_DELAY = 300`。

### 调试参数（正常访问不会带）

| URL | 效果 |
| --- | --- |
| `?wusi_bg=local` | 跳过远端，直接本地兜底 |
| `?wusi_bg=remote` | 强制走远端随机 |
| `?wusi_bg=fail` | 故意让远端失败，验证回落（走真实 `onerror` 路径） |
| `?bgimg=<url>` | 强制指定一张背景图（验证头部文字颜色、回滚等），如 `?bgimg=/images/pool/bg/12728082_180635373000_2.webp` |

`window.__wusiBg` 里有 `{settled, source, image, mode}`，`settled: true` 表示最终背景已定下来；
`<html>` 上会出现 `wusi-bg-ready`（有图）和 `wusi-page-banner`（本页用 banner）两个类名。

## 关键实现点（踩过的坑）

1. **以前"背景层看不见"的根因**不是 z-index，而是主题的两层不透明底色：
   ```css
   body  { background: var(--color-background); }
   #wrap { position: absolute; z-index: 1; background: var(--color-background); }
   ```
   任何垫在下面的背景层都会被 `#wrap` 挡住。所以 `wusi-bg.css` 必须把
   `html/body/#container/#wrap` 的底色都放开，只留 `html` 的底色当"还没图"时的兜底。
2. **不要用 `100vw` 铺满**：`100vw` 含滚动条宽度，会把页面撑出横向滚动条（之前踩过）。
   背景层一律 `position: fixed; inset: 0`，banner 图一律 `width: 100%`。
3. **文章页 banner 复用主题已经渲染好的 `#header img`**（`display` 改成 `fixed` 铺满、去掉主题的渐变遮罩），
   而不是再 `new Image()` 下一遍同一张图 —— 它本来就是 `fetchpriority=high` 提前加载的。
4. **文章页 banner 是 `<img>` 直接子元素；普通页面的站点 banner 被 `<picture>` 包着**，
   所以隐藏规则要写成 `#header img`（而不是 `#header > img`），否则首页那张 banner 会露出来。
5. **移动端横向滚动条**：`params.yml` 里给 `#header-title` 加的 `padding: 14px 22px` 与主题的
   `width: 95%` 叠加后实际宽度 = 95% + 44px，窄屏会超出视口。补了
   `box-sizing: border-box; max-width: 100%` 才对。
6. **暗色模式头部标题看不清**：浅色规则里的 `#header-title #logo h1`（两个 id）比
   `html[data-theme="dark"] #header-title h1`（一个 id）优先级高，暗色下 h1 还是 `#333`；
   暗色规则里补上 `#logo` 那一级即可。
7. 首屏不受影响：内联数据只有一小段 JSON；图片全部走 `new Image()` 异步探测或 CSS 背景，
   不阻塞 HTML/CSS/字体。实测 first-contentful-paint 36~84ms，背景图请求在 FCP 之后才开始。
8. **面板居中**（08-17 补）：
   - `#header-title` 是主题的 `position: absolute; width: 95%`，只写 `margin: 0 auto` **不生效**
     （绝对定位元素不靠 auto 外边距居中），实测中心比视口偏左 37~69px；
     改成 `left: 50%; top: 50%; transform: translate(-50%, -50%)` 后横竖都正中。
     主题的入场动画 `fade-in-blur` 只动 `opacity/filter`，和 transform 不冲突。
   - `#wusi-domain-tip`（页底"想获取最新内容…"那条）的行内样式是 `margin: 14px 0 6px`，
     会**覆盖**样式表里的 `margin: 10px auto`，导致面板贴左边（1280 宽时中心偏左 174px）；
     行内改成 `margin: 14px auto 6px` 后居中。
   - `#footer`（版权面板）本身一直是居中的：`max-width:900px; margin:10px auto`，
     内容靠 `#footer-info div{display:flex;justify-content:center}` 居中，不需要动。
9. **面板宽度与主内容对齐**（08-17 再改）：
   - 主内容左右各留 16px：桌面（≥960）是 `#main` / `#sidebar` 的 `margin: 0 16px`，
     手机（≤767）是 `#main` 的 `padding: 0 16px`，所以面板用
     `width: calc(100% - 32px); max-width: 1318px`（1318 = `layout.max_width` 的 1350 减两侧 16px），
     这样两面都正好压在"文章卡片左边缘 ↔ 侧栏右边缘"上；居中靠 `margin auto` / `left:50%+translate`。
   - 768~959px 这段没有侧栏、`#main` 是 `padding: 0 20px`（左右共 40px），
     单独用媒体查询改成 `calc(100% - 40px)`，否则会差 4px。
   - ⚠️ 如果改 `config/_default/params.yml` 里的 `layout.max_width`，要同步改这里的 `1318`
     （= max_width − 32）。
   - 实测（1280 / 1920 / 2560 / 900 / 390 五个视口）：`#header-title`、`#footer`、
     `#wusi-domain-tip` 的左右边缘与「卡片左边缘 / 侧栏右边缘」**完全相等**（差值 0px）；
     手机端同样成立（390 视口下面板 16~364，卡片也是 16~364）。

## 头部：不用面板，文字颜色跟随背景明暗

- `#header-title` 不再有半透明框（`background` / `backdrop-filter` / `padding` / `border-radius` 全部去掉），
  只保留居中（`left/top 50% + translate(-50%,-50%)`）与和主内容对齐的宽度；
- `static/js/wusi-bg.js` 用 `<canvas>` 采样「标题后面那块背景」（按 `background-size: cover`
  把标题区域映射回原图），算平均亮度：`> 0.55` 给 `<html>` 加 `wusi-hero-light`
  （黑字 `#222` + 浅色阴影），否则加 `wusi-hero-dark`（白字 + 深色阴影）；
- 远端图源带 `Access-Control-Allow-Origin: *`，所以 `crossOrigin="anonymous"` 后能读像素；
  读不到（没 CORS / 图挂了）就保持默认的「白字 + 深阴影」，不报错；
- 采样时机：背景定稿（`wusi:bg-settled` 事件）、窗口 `resize`、`load` 后各跑一次；
  `window.__wusiHeroLum` 能看到当次算出的亮度（0~1）。

## 悬停顶部大图 → 内容淡出（对齐 cialloking 的实现）

`wusi-bg.js` 里绑定 `#header` 的 `mouseenter` / `mouseleave`，参数与 cialloking 源码一致：

- 进入 `#header`：`#content` 在 1s 内从 1 线性降到 0.1，再用 2s 从 0.1 降到 0（逐帧改 `opacity`）；
- 移出：立即恢复 1（`#content { transition: opacity .2s ease }` 让恢复柔和）；
- 只影响 `#content`（正文 + 侧栏），页脚通栏、回到顶部按钮不受影响；
- 想调速度改 `wusi-bg.js` 里的 `DURATION1` / `DURATION2` / `MID`。

## 页脚：页面最底部的整条通栏（不是圆角卡片，也不固定在视口上）

> 2026-10-17 修正两次：①先做成「居中圆角面板」→ 不符合主题原生 footer 的整条通栏样式；
> ②又改成了「固定在视口底部」→ 用户说明「贴在底部 = 页面的最后，不是框的底部」。
> 现在就是**页面正常文档流最后一块**的整条通栏：满宽、无圆角、虚线横贯、内容居中，
> 只有滚到页面末尾才看到它。

- `layouts/partials/footer.html` 把 `#footer`（虚线 + 版权 + 字数/阅读时长）、
  域名提示、BLOG 状态徽章**一起**包进 `#wusi-footer-bar`；
- `#wusi-footer-bar`：满宽（`width:100%`，在 `#wrap` 里自然就是内容区宽度）、
  无圆角、半透明 + `backdrop-filter: blur(8px)` 背景，暗色模式换深色半透明；
  它**没有** `position: fixed`，就是普通的块，跟着页面滚动；
- 条内三块都只是**透明、满宽、无圆角、无外边距**的「行」：
  虚线用主题的 `.footer-line`（`width:200%` + 横向滚动动画）正好横贯整条；
- 回到顶部按钮保持主题默认的右下角（`bottom:30px`、`z-index:999`），
  滚到页面最后时浮在这条通栏右侧上方。

## 副标题打字效果（主题自带 Typed.js）
