第一次用 / 打不开？看这里
  1. Cloudflare → Workers & Pages → 项目 wstk → Settings → Environment variables
  2. 加 ADMIN_TOKEN（类型选 Secret，建议 32 位以上随机串；不要和 GITHUB_TOKEN 混用）
  3. 可选加 ADMIN_NAME（博主回复的昵称，默认「博主」）
  4. Deployments → 最新一次 → Redeploy（wstk 不跟随 push 自动构建，必须手动重新部署）
